Classic Arcade

A lightweight native arcade launcher for local classic games, built with pygame-ce and designed for keyboard, mouse, and controller play.

Download for Windows

Release assets are built by GitHub Actions and published to the public Classic Arcade downloads repository.

Playable Games

  • Pong with vs-computer and two-player modes
  • BlackJack
  • Solitaire and FreeCell
  • Memory with solo and hot-seat play
  • Rock Paper Scissors Lizard Spock
  • Asteroids

Built for Local Play

Player profiles, shared keyboard controls, mouse input, and controller assignment live at the arcade level so games can share a consistent setup.

Small Footprint

Classic Arcade is packaged as a native Python/pygame-ce app. It avoids browser shells and Electron-style wrappers so installs stay simple.

Release Packages

GitHub Actions builds a Windows native package from the private source repository and publishes the installer archive to the public downloads repository. macOS and Linux package notes will be added after release testing.
