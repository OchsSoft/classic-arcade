# OchsSoft Classic Arcade Downloads

This repository hosts public release downloads for OchsSoft Classic Arcade.

The game is free to download and play. This repository hosts release assets; game and website source are maintained separately.

Choose an available package from the latest release:

- Windows: `ClassicArcade-windows.zip`. Extract the archive and launch `ClassicArcade.exe`.
- Linux x86_64: `ClassicArcade-linux-x86_64.tar.gz`, with a matching `.sha256` checksum. Extract the archive and run `./ClassicArcade/ClassicArcade`. The release targets graphical desktops with glibc 2.35 or newer. On NixOS, use `steam-run ./ClassicArcade/ClassicArcade`.

Packages include Python and the arcade dependencies. Keep the extracted program folder together. Package availability is determined by the files attached to each release.

Download the latest release from:

https://github.com/OchsSoft/classic-arcade/releases/latest
