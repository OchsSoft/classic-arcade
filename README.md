# OchsSoft Classic Arcade Downloads

This repository hosts the public download page and public release downloads for OchsSoft Classic Arcade.

The game is free to download and play, but this repository is not the source repository. Public releases currently include a Windows package. macOS and Linux packaging are planned for future releases.

## Public Site

The static download page lives in `docs/` and is intended to serve `classic.ochssoft.com`.

GitHub Pages settings:

- Source: deploy from branch
- Branch: `develop`
- Folder: `/docs`

Cloudflare Pages settings:

- Production branch: `develop`
- Framework preset: `None`
- Build command: `exit 0`
- Build output directory: `docs`

https://github.com/OchsSoft/classic-arcade/releases/latest
